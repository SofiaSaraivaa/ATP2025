# Aplicação de Exercícios de Listas, Strings e Rede Social

Este TPC contém **funções de manipulação de listas, strings e simulação de uma rede social**, permitindo realizar operações como filtragem, cálculo, busca, criação e remoção de posts.

## Funcionalidades

### Exercícios com listas
- **Elementos não comuns a duas listas**  
  Cria uma lista com os elementos que não aparecem em ambas as listas.
- **Palavras com mais de 3 letras**  
  Gera uma lista das palavras de um texto que têm mais de 3 letras.
- **Índice e valor de uma lista**  
  Cria uma lista de pares `(índice, valor)` a partir de uma lista dada.

### Exercícios com strings
- **Contagem de substring**  
  Conta o número de vezes que uma substring aparece numa string, sem sobreposição.
- **Produto dos 3 menores números**  
  Calcula o produto dos três menores números de uma lista.
- **Redução consecutiva de um número**  
  Soma os dígitos de um número repetidamente até resultar em um único dígito.
- **Índice da primeira ocorrência**  
  Retorna o índice da primeira ocorrência de uma substring numa string, ou -1 se não existir.

### Rede Social
- **Número de posts registados**  
  Retorna quantos posts existem na rede social.
- **Posts de um determinado autor**  
  Lista todos os posts de um autor específico.
- **Lista de autores ordenada**  
  Retorna todos os autores de posts, ordenados alfabeticamente.
- **Adicionar novo post**  
  Permite criar e inserir um novo post na rede social.
- **Remover post por ID**  
  Remove um post com base no seu identificador.
- **Distribuição de posts por autor**  
  Calcula quantos posts cada autor tem registados.
- **Posts comentados por um autor**  
  Lista todos os posts que receberam comentários de um autor específico.
