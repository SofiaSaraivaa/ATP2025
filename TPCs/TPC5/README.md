# Aplicação de Gestão de Turmas

Este tpc permite **gerir uma turma de alunos**, possibilitando a criação da turma, inserção e consulta de alunos, bem como a gravação e leitura dos dados a partir de um ficheiro.

## Funcionalidades

A aplicação disponibiliza as seguintes opções:

### Gestão da turma
- **Criar uma turma**  
  Permite criar uma turma com vários alunos, introduzindo os seus dados.
- **Inserir um aluno**  
  Adiciona um novo aluno à turma, evitando duplicados.
- **Listar a turma**  
  Mostra todos os alunos da turma com as respetivas notas.
- **Consultar aluno por ID**  
  Permite procurar um aluno específico através do seu identificador.

### Ficheiros
- **Guardar turma em ficheiro**  
  Guarda os dados da turma num ficheiro de texto.
- **Carregar turma de um ficheiro**  
  Lê os dados de um ficheiro e recria a turma em memória.
