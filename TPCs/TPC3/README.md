# Aplicação de Manipulação de Listas

Este tpc consiste em **criar e manipular listas de números inteiros**, através de um menu interativo.  
O utilizador pode gerar listas automaticamente ou introduzir os valores manualmente, e depois realizar várias operações sobre essas listas.

---

## Funcionalidades

A aplicação disponibiliza as seguintes operações:

### Criação da lista
- **Criar lista aleatória**  
  Gera uma lista com `N` números aleatórios entre 1 e 100.
- **Criar lista introduzida pelo utilizador**  
  O utilizador escolhe manualmente cada elemento da lista.

### Operações sobre a lista
- **Soma** dos elementos da lista
- **Média** dos valores
- **Maior elemento**
- **Menor elemento**
- Verificar se a lista está ordenada por:
  - ordem **crescente**
  - ordem **decrescente**
