# Aplicação para Gerir um Cinema

Este tpc permite **gerir um cinema**, controlando os filmes em exibição, os lugares disponíveis e a venda de bilhetes.  


## Funcionalidades

A aplicação disponibiliza as seguintes opções:


- **Listar filmes em exibição**: Mostra todos os filmes disponíveis, o número total de lugares e os lugares já vendidos.
- **Adicionar um novo filme ao cinema**: Permite criar uma nova sala associada a um filme.
- **Verificar se um lugar está disponível**: Indica se um determinado lugar de uma sessão já está ocupado ou não.
- **Comprar bilhete**: Regista a ocupação de um lugar para um filme específico.
- **Listar lugares disponíveis**: Mostra quantos lugares ainda estão livres em cada sessão.
